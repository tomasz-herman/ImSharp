# ImSharp

Autogenerated, compile-time C# bindings for the full **Dear ImGui** ecosystem, powered by a Roslyn incremental source generator (`ImSharpGenerator`) and a self-contained CMake native library (`ImSharpNative`).

## Supported Products (All 9 `cimgui`-Family Libraries)

| :--- | :--- | :--- | :--- | :--- |

## Architecture

- **`ImSharpNative/`** — Self-contained CMake build that fetches pinned versions of all 9 `cimgui`-family repos and GLFW headers via `FetchContent` (no `vcpkg` required) and compiles them with GLFW + OpenGL3 backends into a single shared library (`libImSharpNative.so` / `ImSharpNative.dll` / `libImSharpNative.dylib`).
- **`ImSharpGenerator/`** — Extensible Roslyn `IIncrementalGenerator` that reads `typedefs_dict.json`, `structs_and_enums.json`, and `definitions.json` from every fetched library at compile time and emits:
  - Strongly-typed C# enums (with `[Flags]` and exact underlying types)
  - Blittable `LayoutKind.Sequential` structs (supporting fixed primitive buffers, `[InlineArray]` non-primitive arrays, explicit-layout anonymous unions, packed bitfields, and opaque forward-declared structs)
  - Raw `[DllImport("ImSharpNative")]` bindings (`*Native` classes)
  - Idiomatic C# static wrappers with stack-allocated UTF-8 string marshalling, `bool` conversions, `ref` overloads, and C# default arguments
  - Automatic fallback namespace/class derivation for any future `cimgui`-style library added to `CMakeLists.txt`
- **`ImSharp/`** — Managed runtime library containing handwritten interop helpers (`ImVector<T>`, `ImSpan<T>`, `ImPool<T>`, `ImVec2`/`ImVec4` operators and `System.Numerics` conversions, `ScopedUtf8String`) and GLFW / OpenGL3 backend bindings (`ImSharp.Backends.ImGuiImplGlfw`, `ImSharp.Backends.ImGuiImplOpenGL3`).
- **`ImSharpOpenTKDemo/`** — Interactive OpenTK + GLFW + OpenGL3 demo.
- **`ImSharp.Tests/`** — xUnit integration tests verifying native ABI struct sizes (`sizeof`), Dear ImGui version, and headless rendering across all 9 libraries.

## Building & Testing

Prerequisites: `.NET 10 SDK`, `CMake >= 3.21`, and a C++17 compiler (`g++`, `clang++`, or MSVC).

```bash
# Build native library, run source generator, and compile all projects
dotnet build ImSharp.sln

# Run ABI & headless integration tests across all 9 libraries
dotnet test ImSharp.sln

# Run the interactive OpenTK demo
dotnet run --project ImSharpOpenTKDemo
```

## Updating or Adding Upstream Libraries

All upstream versions and feature toggles are pinned at the top of `ImSharpNative/CMakeLists.txt`. To upgrade a library, update its tag/commit, delete `ImSharpNative/cmake-build`, and run `dotnet test ImSharp.sln`. To add a new `cimgui`-compatible library, add its `FetchContent` entry to `ImSharpNative/CMakeLists.txt` — `ImSharpGenerator` automatically discovers its `generator/output/*.json` metadata and generates bindings for it.
