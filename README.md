# ImSharp

Compile-time autogenerated C# bindings (safe + raw P/Invoke) for Dear ImGui 1.93 (docking + multi-viewports) and the `cimgui` family.

## Install

```bash
dotnet add package ImSharp
```

## Libraries

| Library | Namespace | Wrapper | Native | CMake Option |
| :--- | :--- | :--- | :--- | :--- |
| Dear ImGui 1.93 (docking) | `ImSharp` | `ImGui` | `ImGuiNative` | Always enabled |
| ImPlot 1.1 | `ImSharp` | `ImPlot` | `ImPlotNative` | `IMSHARP_ENABLE_IMPLOT` |
| ImPlot3D 0.5 | `ImSharp` | `ImPlot3D` | `ImPlot3DNative` | `IMSHARP_ENABLE_IMPLOT3D` |
| imnodes (Nelarius) | `ImSharp` | `ImNodes` | `ImNodesNative` | `IMSHARP_ENABLE_IMNODES` |
| ImNodes (rokups) | `ImSharp.NodesR` | `ImNodesR` | `ImNodesRNative` | `IMSHARP_ENABLE_IMNODES_R` |
| imgui-node-editor (thedmd) | `ImSharp.NodeEditor` | `ImNodeEditor` | `ImNodeEditorNative` | `IMSHARP_ENABLE_IMNODES_EDITOR` |
| ImGuizmo | `ImSharp` | `ImGuizmo` | `ImGuizmoNative` | `IMSHARP_ENABLE_IMGUIZMO` |
| imGuIZMO.quat | `ImSharp.GuizmoQuat` | `ImGuizmoQuat` | `ImGuizmoQuatNative` | `IMSHARP_ENABLE_IMGUIZMO_QUAT` |
| ImGuiColorTextEdit | `ImSharp.ColorTextEdit` | `ImColorTextEdit` | `ImColorTextEditNative` | `IMSHARP_ENABLE_IMCTE` |

## Backends (`ImSharp.Backends`)

- Always built: `ImGuiImplGlfw`, `ImGuiImplOpenGL3`, `ImGuiImplOpenGL2`, `ImGuiImplNull`
- Auto-enabled when headers/SDKs are present: `ImGuiImplVulkan`, `ImGuiImplSDL2`, `ImGuiImplSDLRenderer2`, `ImGuiImplSDL3`, `ImGuiImplSDLRenderer3`, `ImGuiImplSDLGPU3`
- Windows: `ImGuiImplWin32`, `ImGuiImplDX9`, `ImGuiImplDX10`, `ImGuiImplDX11`, `ImGuiImplDX12`

## Build, Test, Pack

Requires `.NET 10 SDK`, `CMake >= 3.21`, and a C++17 compiler.

```bash
dotnet build ImSharp.sln
dotnet test ImSharp.sln
dotnet run --project ImSharpOpenTKDemo          # Linux multi-viewports: GLFW_PLATFORM=x11 dotnet run --project ImSharpOpenTKDemo
dotnet pack ImSharp/ImSharp.csproj -c Release
```

## Updating Upstream Versions

Pinned tags/commits live at the top of `ImSharpNative/CMakeLists.txt`. Update the tag, delete `ImSharpNative/cmake-build`, and run `dotnet test ImSharp.sln`.
